# ویجت‌های اختصاصی المنتور — زیته (Ziteh Elementor Widgets)

مجموعه‌ای از ویجت‌های اختصاصی المنتور برای پیاده‌سازی **پیکسل‌به‌پیکسل** صفحه اصلی فروشگاه زیته. هر سکشن طرح یک ویجت مستقل و کاملاً قابل‌ویرایش در پنل المنتور دارد.

## سکشن‌ها / ویجت‌ها

هر ۱۴ سکشن طرح، از هدر تا فوتر، به‌صورت یک ویجت جداگانه پیاده شده‌اند و همگی در دسته‌بندی **«زیته»** در پنل المنتور قرار می‌گیرند:

| # | ویجت | سکشن طرح |
|---|------|----------|
| ۱ | `زیته | تاپ‌بار` | نوار بالای هدر: سبد خرید، جستجو، ورود/ثبت‌نام |
| ۲ | `زیته | هدر و منو` | لوگو + منوی اصلی |
| ۳ | `زیته | هیرو` | بنر اصلی «جوانه‌ای برای مراقبت از خودت» |
| ۴ | `زیته | داستان زیته` | متن + تصویر برگ |
| ۵ | `زیته | دسته‌بندی‌ها` | اسلایدر دسته‌بندی‌های محبوب |
| ۶ | `زیته | روتین پوست` | تاگل صبح/شب + مراحل روتین |
| ۷ | `زیته | محصولات منتخب` | اسلایدر کارت محصول |
| ۸ | `زیته | برندها` | ردیف لوگوی برندهای معتبر |
| ۹ | `زیته | مجله (بلاگ)` | گرید سه‌ستونه مقالات |
| ۱۰ | `زیته | بنر مشاوره` | بنر CTA «از اینجا شروع کن» |
| ۱۱ | `زیته | نظرات مشتریان` | تستیمونیال‌ها با ستاره و آواتار |
| ۱۲ | `زیته | اینستاگرام` | گرید تصاویر اینستاگرام |
| ۱۳ | `زیته | خبرنامه` | فرم عضویت در خبرنامه |
| ۱۴ | `زیته | فوتر` | فوتر چندستونه + شبکه‌های اجتماعی |

## پیش‌نیازها

- WordPress 5.9+
- PHP 7.4+
- افزونه **Elementor** نسخه 3.5.0 یا بالاتر (نسخه رایگان کافی است)

## نصب

1. پوشه `ziteh-elementor` را در مسیر `wp-content/plugins/` کپی کنید.
2. از پیشخوان وردپرس، در بخش **افزونه‌ها**، افزونه **«Ziteh Elementor Widgets»** را فعال کنید.
3. یک برگه جدید بسازید و آن را با **Elementor** ویرایش کنید.
4. در پنل سمت راست، دسته‌بندی **«زیته»** را باز کنید و ویجت‌ها را به ترتیب طرح روی صفحه بکشید.

> پیشنهاد چیدمان برای بازسازی دقیق صفحه اصلی (از بالا به پایین):
> تاپ‌بار ← هدر و منو ← هیرو ← داستان زیته ← دسته‌بندی‌ها ← روتین پوست ← محصولات منتخب ← برندها ← مجله ← بنر مشاوره ← نظرات مشتریان ← اینستاگرام ← خبرنامه ← فوتر
>
> برای حذف فاصله‌ی پیش‌فرض بین سکشن‌ها، در تنظیمات هر Section/Container مقدار Padding را صفر کنید؛ فاصله‌های عمودی داخل خود ویجت‌ها لحاظ شده است.

## سفارشی‌سازی

- **محتوا:** تمام متن‌ها، لینک‌ها، تصاویر و آیتم‌های تکرارشونده (منو، دسته‌بندی‌ها، محصولات، مقالات، نظرات، ستون‌های فوتر و…) از داخل پنل المنتور قابل ویرایش‌اند.
- **رنگ‌ها:** هر ویجت تب **استایل** دارد؛ افزون بر آن، پالت کلی در فایل `assets/css/ziteh-widgets.css` در قالب متغیرهای CSS (`:root`) تعریف شده و با تغییر آن‌ها کل ظاهر به‌صورت یکپارچه عوض می‌شود.
- **فونت:** فونت فارسی **وزیرمتن (Vazirmatn)** به‌صورت پیش‌فرض از CDN بارگذاری می‌شود (`assets/fonts/vazirmatn.css`). برای میزبانی محلی، فایل‌های `woff2` را در همان پوشه قرار داده و آدرس `src` را اصلاح کنید.

## ساختار فایل‌ها

```
ziteh-elementor/
├── ziteh-elementor.php              # فایل اصلی افزونه (bootstrap + بررسی سازگاری)
├── includes/
│   └── class-ziteh-widgets-manager.php   # ثبت دسته‌بندی، بارگذاری اسکریپت/استایل و ویجت‌ها
├── widgets/
│   ├── class-ziteh-widget-base.php  # کلاس پایه مشترک + آیکون‌های SVG
│   └── class-ziteh-*.php            # یک فایل برای هر سکشن
└── assets/
    ├── css/ziteh-widgets.css        # استایل پیکسل‌پرفکت همه سکشن‌ها (RTL)
    ├── js/ziteh-widgets.js          # اسلایدر، تاگل صبح/شب، منوی موبایل
    └── fonts/vazirmatn.css          # فونت فارسی وزیرمتن
```

## واکنش‌گرایی (Responsive)

طراحی موبایل‌فرست برای عرض‌های زیر پوشش داده شده است: دسکتاپ، تبلت (≤۱۰۲۴px)، موبایل (≤۸۶۰px و ≤۵۶۰px). منوی هدر در موبایل به دکمه‌ی همبرگری تبدیل می‌شود و گریدها تک‌ستونه می‌شوند.
