# هسته زیته (Ziteh Core)

هسته مرکزی زیته برای مدیریت ویجت‌های اختصاصی Elementor، امکانات WooCommerce، طراحی، تعاملات، کارایی و توسعه‌های آینده. هر سکشن یک ویجت مستقل و کاملاً قابل‌ویرایش دارد.

## سکشن‌ها / ویجت‌ها

هسته زیته ۲۰ ویجت مستقل ثبت می‌کند. قالب آماده صفحه اصلی شامل ۱۷ ویجت است و سه ویجت «صفحه محصول حرفه‌ای»، «اطلاعات تکمیلی محصول» و «محصولات مرتبط» برای صفحات محصول به‌صورت جداگانه استفاده می‌شوند. همه ویجت‌ها در دسته‌بندی **«هسته زیته»** قرار می‌گیرند:

| # | ویجت | سکشن طرح |
|---|------|----------|
| ۱ | `زیته | تاپ‌بار` | نوار بالای هدر: سبد خرید، جستجو، ورود/ثبت‌نام |
| ۲ | `زیته | هدر و منو` | لوگو + منوی اصلی |
| ۳ | `زیته | هیرو (اسلایدر تصویری)` | اسلایدر تصویری تمام‌عرض با اتوپلی، فلش و نقطه |
| ۳.۵ | `زیته | نوار مزیت‌ها` | نوار اعتماد (اصالت، ارسال، بازگشت، پشتیبانی) |
| ۴ | `زیته | داستان زیته` | متن + تصویر برگ |
| ۵ | `زیته | دسته‌بندی‌ها` | اسلایدر دسته‌بندی‌های محبوب |
| ۶ | `زیته | روتین پوست` | تاگل صبح/شب + مراحل روتین |
| ۷ | `زیته | محصولات منتخب` | اسلایدر محصول — داینامیک از ووکامرس یا دستی |
| ۷.۲۵ | `زیته | صفحه محصول حرفه‌ای` | گالری، خرید، مشخصات، دیدگاه‌ها و محصولات مرتبط ووکامرس |
| ۷.۳۵ | `زیته | اطلاعات تکمیلی محصول` | تب‌های توضیحات، ترکیبات، نحوه استفاده، نظرات و مزایای محصول |
| ۷.۴ | `زیته | محصولات مرتبط` | اسلایدر داینامیک محصولات مرتبط با خرید سریع ووکامرس |
| ۷.۵ | `زیته | پیشنهادهای ویژه` | اسلایدر محصولات تخفیف‌دار + تایمر شمارش معکوس |
| ۸.۵ | `زیته | کوییز پوست` | مشاوره چندمرحله‌ای با پیشنهاد روتین/محصول |
| ۸ | `زیته | برندها` | ردیف لوگوی برندهای معتبر |
| ۹ | `زیته | مجله (بلاگ)` | گرید مقالات — داینامیک از نوشته‌های وردپرس یا دستی |
| ۱۰ | `زیته | بنر مشاوره` | بنر CTA «از اینجا شروع کن» |
| ۱۱ | `زیته | نظرات مشتریان` | تستیمونیال‌ها با ستاره و آواتار |
| ۱۲ | `زیته | اینستاگرام` | گرید تصاویر اینستاگرام |
| ۱۳ | `زیته | خبرنامه` | فرم عضویت در خبرنامه |
| ۱۴ | `زیته | فوتر` | فوتر چندستونه + شبکه‌های اجتماعی |

## پیش‌نیازها

- WordPress 5.9+
- PHP 7.4+
- افزونه **Elementor** نسخه 3.5.0 یا بالاتر (نسخه رایگان کافی است)

## نصب

1. پوشه `ziteh-elementor` را در مسیر `wp-content/plugins/` کپی کنید.
2. از پیشخوان وردپرس، در بخش **افزونه‌ها**، افزونه **«هسته زیته»** را فعال کنید.

### روش ۱ (پیشنهادی): ساخت خودکار صفحه آماده — یک کلیک

پس از فعال‌سازی، به منوی **المنتور ← «قالب آماده زیته»** بروید. شش چیدمان کامل آنجاست و هرکدام با یک کلیک ساخته می‌شود:

| قالب | خروجی | نکته |
| --- | --- | --- |
| صفحه اصلی | برگه المنتور (Canvas) | ۱۷ سکشن از تاپ‌بار تا فوتر |
| درباره ما | برگه المنتور (Canvas) | مسیر برند، داستان، مزیت‌ها، تیم، نظرات، مشاوره |
| تماس با ما | برگه المنتور (Canvas) | راه‌های ارتباطی، فرم AJAX، نقشه، خدمات فروشگاه |
| آرشیو مقالات | برگه المنتور (Canvas) | کارت‌های مقاله + خبرنامه |
| تک مقاله | سند کتابخانه (`single-post`) | نیازمند المنتور پرو |
| هدر / فوتر سایت | سند کتابخانه (`header` / `footer`) | نیازمند المنتور پرو |

سه قالب آخر برای اینکه به سایت وصل شوند به **سازنده قالب المنتور پرو** نیاز دارند و بدون آن ساخته نمی‌شوند. شرط نمایششان از پیش تنظیم نمی‌شود؛ تا وقتی خودتان در سازنده قالب شرط را نگذارید، هیچ تغییری در سایت دیده نمی‌شود.

اگر پرو ندارید، مثل قبل ویجت‌های تاپ‌بار، هدر و فوتر را داخل خود برگه‌ها نگه دارید. قالب وردپرسی زیته هم بدون پرو هدر و فوتر پیش‌فرض خودش را نشان می‌دهد.

### روش ۲: ایمپورت دستی قالب

در المنتور به **«قالب‌ها ← قالب‌های ذخیره‌شده ← ایمپورت»** بروید و هرکدام از فایل‌های زیر را بارگذاری کنید:

```
wp-content/plugins/ziteh-elementor/templates/ziteh-home.json
wp-content/plugins/ziteh-elementor/templates/ziteh-about.json
wp-content/plugins/ziteh-elementor/templates/ziteh-contact.json
wp-content/plugins/ziteh-elementor/templates/ziteh-articles.json
wp-content/plugins/ziteh-elementor/templates/ziteh-single-post.json
wp-content/plugins/ziteh-elementor/templates/ziteh-header.json
wp-content/plugins/ziteh-elementor/templates/ziteh-footer.json
```

### روش ۳: چیدن دستی ویجت‌ها

یک برگه‌ی جدید بسازید و با المنتور ویرایش کنید؛ در پنل، دسته‌بندی **«هسته زیته»** را باز کرده و ویجت‌ها را به این ترتیب روی صفحه بکشید:

> تاپ‌بار ← هدر و منو ← هیرو ← داستان زیته ← دسته‌بندی‌ها ← روتین پوست ← محصولات منتخب ← برندها ← مجله ← بنر مشاوره ← نظرات مشتریان ← اینستاگرام ← خبرنامه ← فوتر
>
> برای حذف فاصله‌ی پیش‌فرض بین سکشن‌ها، Padding هر Section/Column را صفر کنید؛ فاصله‌های عمودی داخل خود ویجت‌ها لحاظ شده است.

## قابلیت‌های حرفه‌ای هسته زیته ۳

- **بوم ایزوله صفحه محصول:** در صفحات محصول، استایل‌های نمایشی WooCommerce و محدودیت‌های کانتینر قالب غیرفعال می‌شوند و ظاهر پنج ویجت محصول فقط از CSS اختصاصی زیته پیروی می‌کند. این قابلیت از بخش «کارایی و سازگاری» قابل کنترل است.

- **دسته مستقل محصول تکی:** پنج ویجت اختصاصی قالب محصول در دسته «محصول تکی زیته» و با ترتیب شماره‌گذاری‌شده نمایش داده می‌شوند؛ شناسه‌ها برای سازگاری با صفحات قبلی بدون تغییر مانده‌اند.

- **ویجت نوار خدمات فروشگاه:** نمایش خدمات ارسال، بازگشت، بسته‌بندی و پشتیبانی با Repeater نامحدود، Icon Library، لینک مستقل، کنترل کامل استایل و سه چیدمان واکنش‌گرا.

- **ویجت نظرات کاربران محصول:** نمایش پویای دیدگاه‌های تأییدشده، امتیاز میانگین و توزیع پنج‌ستاره WooCommerce با آواتار، تاریخ، نشان خریدار، کنترل کامل محتوا و استایل، داده ساختاریافته Review و طراحی واکنش‌گرا.

- **مرکز تنظیمات حرفه‌ای:** نمای کلی، سیستم طراحی، امکانات، کارایی و اطلاعات سیستم در منوی «هسته زیته».
- **کنترل مستقل قابلیت‌ها:** Quick View، جستجوی زنده، سبد کشویی، علاقه‌مندی، پیشنهاد کوییز، هدر چسبان و انیمیشن‌ها.
- **بارگذاری هوشمند:** امکان انتخاب بارگذاری assets فقط در صفحات موردنیاز یا به‌صورت سراسری.
- **کنترل فونت و کش:** قطع CDN فونت و فعال/غیرفعال‌کردن پاک‌سازی خودکار کش.
- **API توسعه تنظیمات:** ماژول‌های آینده می‌توانند از هوک‌های `ziteh_core_default_settings`، `ziteh_core_sanitize_settings`، `ziteh_core_settings_panels` و `ziteh_core_settings_system` استفاده کنند.

- **ویجت نوار مزیت‌ها (USP):** اصالت کالا، ارسال سریع، ضمانت بازگشت، پشتیبانی.
- **ویجت کوییز پوست:** مشاوره‌ی چندمرحله‌ای با نوار پیشرفت و صفحه نتیجه (سؤالات و نتیجه از پنل قابل ویرایش).
- **Quick View:** روی هر کارت محصول، «مشاهده سریع» → مُدال با گالری، قیمت و افزودن به سبد بدون ترک صفحه.
- **مینی‌کارت کشویی (Drawer):** با افزودن به سبد، سبد از کنار باز می‌شود، شمارنده‌ی هدر با AJAX به‌روز می‌شود.
- **علاقه‌مندی واقعی:** قلب کارت‌ها با ذخیره در مرورگر (localStorage) فعال است.
- **جستجوی زنده (Live Search):** کلیک روی جستجو → اورلی با نتایج لحظه‌ای محصولات.
- **نشان کمبود موجودی** روی کارت («فقط N عدد باقی مانده») و **نوار «٪ فروخته‌شده»** در پیشنهاد ویژه.
- **هاور تصویر دوم** روی کارت محصول (اولین تصویر گالری).
- **انیمیشن اسکرول** برای همه‌ی سکشن‌ها و **هدر چسبان جمع‌شونده**.
- **پنل تنظیمات مرکزی** (منوی «زیته» در پیشخوان): کنترل رنگ‌ها، گردی گوشه‌ها و انیمیشن‌ها از یک جا برای کل قالب.

> بیشتر این قابلیت‌ها (Quick View، مینی‌کارت، جستجوی زنده، کمبود موجودی، فروش‌رفته) به **ووکامرس** وابسته‌اند و در نبودش به‌آرامی غیرفعال می‌شوند.

## محتوای داینامیک

سه ویجت به‌صورت پویا محتوا می‌خوانند و نیازی به ورود دستی ندارند:

- **هیرو (اسلایدر تصویری):** فقط تصاویر را در repeater «اسلایدها» بگذارید؛ اتوپلی، سرعت، فلش، نقطه، ارتفاع و گردی گوشه‌ها قابل تنظیم است. با هاور، اتوپلی متوقف می‌شود.
- **محصولات منتخب:** در بخش «منبع محصولات» گزینه‌ی **ووکامرس (داینامیک)** را انتخاب کنید. محصولات واقعی فروشگاه با قیمت، تصویر شاخص، برچسب تخفیف و دکمه‌ی افزودن به سبد (با پشتیبانی ajax) نمایش داده می‌شوند. تنظیمات: تعداد، مرتب‌سازی (جدیدترین/پرفروش/امتیاز/قیمت)، فیلتر (ویژه/تخفیف‌دار/موجود) و دسته‌بندی. اگر ووکامرس فعال نباشد، به‌صورت خودکار محتوای دستی نمایش داده می‌شود.
- **مجله (مقالات):** در بخش «منبع مقالات» گزینه‌ی **نوشته‌های وردپرس (داینامیک)** را انتخاب کنید. نوشته‌های واقعی با تصویر شاخص، دسته و لینک نمایش داده می‌شوند. تنظیمات: نوع محتوا، تعداد، مرتب‌سازی و دسته‌بندی.

## سفارشی‌سازی

- **محتوا:** تمام متن‌ها، لینک‌ها، تصاویر و آیتم‌های تکرارشونده (منو، دسته‌بندی‌ها، محصولات، مقالات، نظرات، ستون‌های فوتر و…) از داخل پنل المنتور قابل ویرایش‌اند.
- **رنگ‌ها:** هر ویجت تب **استایل** دارد؛ افزون بر آن، پالت کلی در فایل `assets/css/ziteh-widgets.css` در قالب متغیرهای CSS (`:root`) تعریف شده و با تغییر آن‌ها کل ظاهر به‌صورت یکپارچه عوض می‌شود.
- **فونت:** فونت فارسی **وزیرمتن (Vazirmatn)** به‌صورت پیش‌فرض از CDN بارگذاری می‌شود (`assets/fonts/vazirmatn.css`). برای میزبانی محلی، فایل‌های `woff2` را در همان پوشه قرار داده و آدرس `src` را اصلاح کنید.

## ساختار فایل‌ها

```
ziteh-elementor/
├── ziteh-elementor.php              # فایل اصلی افزونه (bootstrap + بررسی سازگاری)
├── includes/
│   ├── class-ziteh-widgets-manager.php   # ثبت دسته‌بندی، بارگذاری اسکریپت/استایل و ویجت‌ها
│   └── class-ziteh-template-importer.php # ایمپورتر یک‌کلیکی قالب‌های آماده
├── widgets/
│   ├── class-ziteh-widget-base.php  # کلاس پایه مشترک + آیکون‌های SVG
│   └── class-ziteh-*.php            # یک فایل برای هر سکشن
├── templates/
│   ├── ziteh-home.json              # قالب صفحه اصلی (چیدمان ۱۷ ویجت)
│   ├── ziteh-about.json             # قالب صفحه درباره ما
│   ├── ziteh-contact.json           # قالب صفحه تماس با ما
│   ├── ziteh-articles.json          # قالب آرشیو مقالات
│   └── ziteh-single-post.json, ziteh-header.json, ziteh-footer.json  # اسناد سازنده قالب (پرو)
└── assets/
    ├── css/ziteh-widgets.css        # استایل پیکسل‌پرفکت همه سکشن‌ها (RTL)
    ├── js/ziteh-widgets.js          # اسلایدر، تاگل صبح/شب، منوی موبایل
    └── fonts/vazirmatn.css          # فونت فارسی وزیرمتن
```

## واکنش‌گرایی (Responsive)

طراحی موبایل‌فرست برای عرض‌های زیر پوشش داده شده است: دسکتاپ، تبلت (≤۱۰۲۴px)، موبایل (≤۸۶۰px و ≤۵۶۰px). منوی هدر در موبایل به دکمه‌ی همبرگری تبدیل می‌شود و گریدها تک‌ستونه می‌شوند.
